# Prayer Journal

A website, admin panel (Studio) and mobile app for prayer, Bible reading and learning, starting with the course **My Prayer Journal: The Believer's Prayer Companion**.

| Folder | What it is |
| --- | --- |
| [`web/`](web/README.md) | Website, Studio admin panel and REST API (CodeIgniter 4, PHP 8.2+) |
| [`mobile/`](mobile/README.md) | iOS/Android app (Expo / React Native) |

**Deploy to cPanel:** clone this repo with Git Version Control, then run `bash ~/prayer-journal/web/deploy.sh` in Terminal. Full steps are in [web/DEPLOYMENT.md](web/DEPLOYMENT.md).

Features: [web/FEATURES.md](web/FEATURES.md).
